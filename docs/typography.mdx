# Typography

The package stylesheet supplies Markdown presentation. Application typography can override wrapper descendants or use native Solid components for headings and paragraphs. Keep code and math styles intact when applying prose rules.

Use semantic headings, links, lists and tables rather than changing their meaning for visual appearance. Verify long links, narrow screens, RTL text, code overflow and reduced motion in your application's theme. No consumer branding or generated custom docs UI is required.
