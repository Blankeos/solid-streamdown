## Use the fork, not an assumed npm release

```bash
git clone --branch feat/streaming-content-animation https://github.com/Blankeos/solid-streamdown.git
cd solid-streamdown
bun install
bun run build
bun link
# In your Solid application's directory:
bun link solid-streamdown
```

The fork's library scripts require **Bun**. Linking uses the local built package and is appropriate for development; rebuild the library when source changes. The application can use npm, pnpm or Bun.

Install the Solid peer dependency in your application if it is not already present:

## Integrate a built package

For reproducible integration, pin a reviewed fork commit and package its build. Do not assume a Git URL installation builds `dist`. From the cloned fork, replace the placeholder with the commit you reviewed:

```bash
git checkout <reviewed-commit>
bun install
bun run build
npm pack
```

The current manifest is still named `solid-streamdown` at version `1.0.1`, so `npm pack` produces `solid-streamdown-1.0.1.tgz`. This is a locally built fork artifact, **not** a new registry release. Use the filename reported by `npm pack` if the version changes. Preserve the reviewed commit and artifact in your production dependency workflow.

Run one of these in your Solid application, replacing the path with your artifact's actual location:

## Render a reactive string

```tsx
import { createSignal } from "solid-js";
import { Streamdown } from "solid-streamdown";
import "solid-streamdown/styles.css";

export function MarkdownView() {
  const [markdown, setMarkdown] = createSignal("# Hello");
  const [streaming, setStreaming] = createSignal(false);
  // Your transport updates these signals; the renderer does not fetch tokens.
  return <Streamdown isAnimating={streaming()}>{markdown()}</Streamdown>;
}
```

Keep signal reads inside JSX. `children` is Markdown text, not an arbitrary Solid child tree. Enable optional features through [native plugins](/plugins). Import KaTeX's stylesheet when using math. The package has server and browser exports; use the package root rather than a browser-only deep import.
