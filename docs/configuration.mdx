The target is React Streamdown **2.7.0**, not an unversioned latest API. Exported declarations in your installed package are the authority for available props. The functional surface is implemented; [the parity checklist](/streamdown-parity) maps source and fixtures and records final verification separately.

Defaults below describe native `Streamdown`, not the [legacy interface](/legacy). Omitted optional props have no configured value unless a fallback is described. These manual maps follow `src/types.ts` and the renderer defaults; they are display strings, not executable configuration.

Pipeline configuration is a trust boundary. Read [security](/security) before replacing plugins or URL policies; element filtering is not sanitation.

Use exported types to keep configuration checked:

```tsx
import {
  Streamdown,
  type StreamdownProps,
  type LinkSafetyConfig,
} from "@blankeos/solid-streamdown";

const linkSafety: LinkSafetyConfig = {
  enabled: true,
  onLinkCheck: (url) => {
    try {
      return new URL(url).origin === "https://example.com";
    } catch {
      return false;
    }
  },
};
const options = {
  mode: "streaming",
  linkSafety,
  lineNumbers: true,
  normalizeHtmlIndentation: true,
} satisfies Omit<StreamdownProps, "children">;

<Streamdown {...options} isAnimating={streaming()}>
  {markdown()}
</Streamdown>;
```

`false` from `onLinkCheck` requests confirmation; it is not a hard navigation denial. See [link safety](/link-safety). Static mode renders a single document and ignores custom block splitting/rendering hooks. `allowedTags` attribute names use canonical HAST property names, for example `dataId`.
