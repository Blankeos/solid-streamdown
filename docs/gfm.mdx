# GitHub Flavored Markdown

The default Markdown pipeline supports GFM tables, task lists, strikethrough and autolinks. Tables can expose Markdown/CSV/TSV copy and Markdown/CSV download actions. Configure `controls.table` and `tableMaxHeight`; disabled controls do not disable Markdown parsing.

Streaming can change an earlier paragraph into a table or resolve a reference definition after its use. Validate those rewrites rather than assuming every chunk corresponds to an independent Markdown block.

`disableAutolinkProtocols` is part of the 2.7.0 target. It should affect automatic links, not explicit `[label](destination)` links; check implementation and fixtures for your checkout before configuring it. URL filtering and navigation confirmation are separate policies.
