# Solid Streamdown

This maintained fork targets **React Streamdown 2.7.0**, with native Solid rendering rather than a React wrapper. The full functional surface is implemented with the goal of 1:1 API and behavior compatibility, using Solid component types and reactive ownership. This does not claim exhaustive performance or security parity. Consult [verification](/streamdown-parity) for mapped fixtures and final-run status.

This documentation describes the fork at [Blankeos/solid-streamdown](https://github.com/Blankeos/solid-streamdown), not a new npm release. The package manifest still says `solid-streamdown@1.0.1`; installing that name from npm does not select this checkout.

Start with [installation](/getting-started), then [usage](/usage) and [configuration](/configuration). The topic coverage follows the upstream documentation, but examples and prose are written for Solid. [Legacy compatibility](/legacy) preserves the original Solid interface.

No React runtime is required. Solid `Component` and `JSX` types replace React component and element types. Native plugin imports live under the same package's `/code`, `/math`, `/cjk`, and `/mermaid` subpaths.
